# Leerformaat-acceptatiecriteria

Type: grilling  
Status: resolved  
Blocked by:

## Question

Welke acceptatiecriteria gelden voortaan voor “leerbare” toetslessen voor Lennart — specifiek: wanneer is een rijtje/paradigma/begrippenlijst **compleet genoeg** (ev+mv, alle personen/naamvallen, …), wanneer mag proza, en wanneer **moet** het een scanbare lijst/tabel zijn die uit het hoofd geleerd wordt?

## Answer

AFK (defaults + diagnose):

1. **Compleet paradigma:** altijd volledig in les én reference (ev+mv / alle personen of cellen die de toets vraagt). “Controleer tegen je boek” mag alleen spelling/accent/boeknummer — nooit ontbrekende helften.
2. **Proza vs punten:** alles wat memoriseerbaar is = scanbare tabel/lijst; proza alleen voor mechanisme (waarom/hoe), max. korte omlijsting.
3. Geldt voor klassieke talen-rijtjes én voor EC-achtige must-know matrices (marktvormen 2×2, formules) — zelfde poort: leerbaar = lijst/tabel eerst.
