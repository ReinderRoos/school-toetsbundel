# EC go/no-go zonder PDF

Type: grilling  
Status: resolved  
Blocked by: 04

## Question

Welke go/no-go-checklist beslist of we Praktische Economie 3 vwo H2 §1–4 (release 6.2) zonder lokale PDF mogen bouwen — minimale publieke bronnen, “controleer tegen je boek”-eis, diepte zonder boektekst, en wanneer we alsnog moeten wachten op het boek?

## Answer

AFK — **GO** voor EC H2 §1–4 zonder PDF als alle punten groen zijn; anders **NO-GO** (stop, vraag boek):

**GO als:**
1. Paragraaftitels + begrippenlijst H2 geverifieerd via ≥2 legale publieke bronnen (uitgever/StudyGo/Ensie/schoolsamenvatting met §-titels).
2. Elke les + reference bevat **complete** must-know tabellen (vraag/aanbod-begrippen, kosten/winst-formules, evenwicht-termen, 2×2 marktvormen) — geen half rijtje.
3. Geen boekpagina’s gekopieerd; wel “controleer cijfers/opdrachtennummers tegen je boek (6.2)”.
4. Leerformaat-regels uit ticket Skill-regels specificeren gevolgd (lijst/tabel eerst; proza = mechanisme).
5. `BOEKEN.md` entry aanwezig met Status ontbreekt + metadata 6.2.

**NO-GO als:**
- Begrippen/§-indeling conflict tussen bronnen en niet beslisbaar zonder boek.
- Toets vraagt boek-specifieke opgaven/cijfers die niet publiek zijn.
- Agent zou half leveren + “check boek” voor ontbrekende definities/cellen.
