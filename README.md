# Toetsbundels (Lennart)

HTML-lessen per vak onder `lessons/<Vak>/`.

## Voor Lennart — zo open je het

**Optie A (makkelijkst):** open  
https://reinderroos.github.io/school-toetsbundel/  
Start bij de homepage; klik door de lessen.

**Optie B (offline):**

1. Ga naar de GitHub-pagina van deze repo.
2. Groene knop **Code** → **Download ZIP**.
3. Pak uit.
4. Open `index.html` in Chrome of Edge (dubbelklik).

Quizzes werken lokaal; je hoeft niets te installeren.
