# AK-toets Chili + India (Lennart)

Lessen en oefeningen voor de Geo 3VWO (H3 §1–3, H5 §1 + §3).

## Voor Lennart — zo open je het

**Optie A (makkelijkst):** open de site-link die je van papa krijgt (GitHub Pages). Start bij de homepage; klik door de lessen.

**Optie B (offline):**

1. Ga naar de GitHub-pagina van deze repo.
2. Groene knop **Code** → **Download ZIP**.
3. Pak uit.
4. Open `index.html` in Chrome of Edge (dubbelklik).

Quizzes werken lokaal; je hoeft niets te installeren.
